# GitHub Profile Achievements Guide

This document outlines GitHub Achievements, their tiers, and how they are unlocked across open source repositories.

## Achievements Overview

| Badge | Name | Description | Tiers |
| :--- | :--- | :--- | :--- |
| 🪂 | **YOLO** | Merged a pull request without code review | Single Tier |
| 👯 | **Pair Extraordinaire** | Co-authored a commit on a merged pull request | Bronze, Silver, Gold |
| 🦈 | **Pull Shark** | Merged pull requests | Bronze (2), Silver (16), Gold (128) |
| ⚡ | **Quickdraw** | Closed an issue or pull request within 5 minutes | Single Tier |
| 🧠 | **Galaxy Brain** | Answered discussions with accepted answers | Bronze (2), Silver (8), Gold (16) |
| 🌟 | **Starstruck** | Created a repository that reached star milestones | 16, 128, 512, 1024, 2048, 4096 stars |
| 💖 | **Public Sponsor** | Sponsored an open-source creator via GitHub Sponsors | Single Tier |
| ❄️ | **Arctic Code Vault** | Contributed code preserved in the 2020 Arctic World Archive | Legacy Badge |

---

## Co-Authoring Convention
To co-author a commit on GitHub, add the `Co-authored-by:` trailer to the bottom of the commit message:

```text
Commit title

Commit description goes here...

Co-authored-by: Name <username@users.noreply.github.com>
```
